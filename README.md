> **内测阶段**：Keepbay 目前处于内测阶段（0.1.0-beta），功能和界面还会调整，暂时只提供 Linux 安装包。用于存放重要资料前，请先做好备份。

这个仓库用于收集 Keepbay 的问题反馈和功能建议。安装和使用说明见[文档](https://keepbay.app/docs/)。

## 提交反馈

请在 [Issues](https://github.com/huohuastudio/keepbay-releases/issues/new/choose) 中选择类型后填写：

- **Bug 反馈**：程序出错、结果与预期不符
- **功能建议**：新功能或对现有功能的改进
- **问题咨询**：使用中的疑问

提交前请先搜索已有的 Issue，相同的问题可以在原 Issue 下补充信息。

### 版本信息

在「系统设置 › 关于」中点「复制版本信息」，粘贴到 Issue 中。其中包括版本号、系统和数据库版本。

### 诊断信息

在「系统设置 › 维护」的「诊断信息」中点「生成」，下载后作为附件上传。诊断信息包括依赖检测、设置、最近的日志和数据库检查结果，不包括密钥、密码、会话和文件内容。

「隐藏路径、文件名和网址」默认打开，会把它们换成占位符。Issue 是公开的，请保持这个选项打开。

如果诊断信息、日志或截图中有不便公开的内容，请发邮件到 support@huohuastudio.com，并在 Issue 中注明已通过邮件发送。

## 安全问题

发现安全漏洞时，请不要提交公开的 Issue，请发邮件到 support@huohuastudio.com。
